# Carteras Inteligentes

Aplicación educativa, cliente-side y en español para construir, entender y revisar una cartera robusta desde España.

## Principios

- Sin backend.
- Sin cuentas.
- Sin tracking.
- Datos calculados en el navegador.
- Enfoque educativo, no asesoramiento financiero personalizado.

## Desarrollo local

```bash
npm install
npm run dev
npm run test:run
npm run build
```

## Estructura

- `docs/PRODUCT.md` — brief de producto.
- `docs/TECHNICAL_BRIEF.md` — brief técnico.
- `.hermes/plans/mvp.md` — plan MVP.
- `src/domain/` — lógica de cartera testeada.
- `src/pages/` — flujo de aplicación.

## MVP actual

- Inicio con promesa de privacidad.
- Perfil inversor.
- Cartera actual editable.
- Cartera objetivo.
- Plan de acción con avisos para inversores en España.
- Exportación local JSON.
